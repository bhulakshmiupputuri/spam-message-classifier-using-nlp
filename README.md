# Spam Message Classifier Using NLP

## Overview
This project classifies SMS messages as spam or not spam
using Natural Language Processing (NLP) and Naive Bayes.

## Dataset
SMS Spam Collection dataset.

## Technologies
- Python
- Pandas
- Scikit-learn
- TF-IDF
- Naive Bayes

## Method
1. Load the SMS dataset.
2. Clean and preprocess the text.
3. Split the data into training and testing sets.
4. Convert text into numerical features using TF-IDF.
5. Train a Naive Bayes classifier.
6. Evaluate the model and classify new messages.
